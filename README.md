OVERVIEW OF PROJECT:

Project : student record management

Objective : The primary objective of this project is to build a lightweight, reliable, and straightforward data management tool while mastering foundational concepts in C programming. 

### Technical Learning Objectives:
* **Data Encapsulation:** Understand how to use C structures (`struct`) to bundle related attributes (ID, name, and GPA) into a single logical entity.
* **Array Manipulation:** Learn to manage a collection of structured elements, including inserting records, iterating for display, and traversing for specific data.
* **I/O Buffer Management:** Master standard input/output operations, specifically handling the common pitfalls of mixing `scanf()` and `fgets()` by properly clearing the input buffer.
* **Modular Code Structure:** Practice writing clean, reusable, and maintainable code by breaking the application logic down into distinct functions with specialized responsibilities.
* **Defensive Programming:** Implement basic validation checks, such as preventing duplicate primary keys (Student IDs) and managing array boundaries to avoid overflow.
